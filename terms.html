利用規約

YouTube Auto Studioは、利用者自身が管理するチャンネルの動画制作と投稿管理を支援するローカルアプリです。

YouTubeへの接続

本アプリは YouTube API Services の YouTube Data API v3 を使用します。本アプリからYouTube API Servicesを使用する場合は、YouTube 利用規約に同意し、同規約に従うものとします。YouTube Auto Studioは独立して開発されたアプリで、GoogleおよびYouTubeの公式サービスではありません。

公開設定と投稿の確認

送信前に、対象チャンネル、完成動画、タイトル、説明、出典、開示情報を確認してください。非公開が既定です。通常の制作ジョブには限定公開・公開の選択肢があり、選択した設定に対して個別の承認が必要です。予約公開は投稿と別の承認が必要です。YouTube側の設定の確認と変更には YouTube Studio を使用できます。

アップロードすることでYouTube利用規約に同意したものとみなされます。他者の著作権やプライバシーを侵害するコンテンツをアップロードしないでください。

改訂版専用の投稿経路では非公開のみを使用します。投稿画面はレビュー済みのタイトルと説明を表示します。投稿画面からタイトルや説明を直接編集する機能はありません。

コンテンツとアカウントの管理

投稿には必要な権利と許諾を得た素材を使用し、YouTubeのルールと適用法令を守ってください。OAuth設定、ローカルの認証ファイル、投稿履歴はPCの利用者が管理します。APIやサービスの状態によって操作の結果を確認できない場合は、状況を確認するまで同じ操作を繰り返さないでください。

データの取り扱いと連絡先

データの利用・保存・削除方法とアクセス権の取り消し手順は 本アプリのプライバシーポリシーを参照してください。Googleによる情報の取り扱いは Google プライバシーポリシーに記載されています。
