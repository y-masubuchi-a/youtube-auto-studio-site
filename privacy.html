プライバシーポリシー

YouTube Auto Studioが利用者のPCとGoogle・YouTubeの間で取り扱うデータを説明します。

取得するデータと利用目的

本アプリは YouTube API Services の YouTube Data API v3 を使用します。Google OAuthで認証し、統合モードには youtube.force-ssl を使用します。

チャンネル名とチャンネルID
認証されたチャンネルを特定し、操作対象と照合します。
動画IDと投稿情報
動画のタイトル、説明、公開設定、公開予定日時、処理状態、APIから返る開示設定などを取得し、操作の確認、投稿履歴と状態の照合、重複投稿の防止に使用します。
OAuth認証情報
Googleから受け取るアクセストークンと更新トークンを、認証済みAPI操作とアクセストークンの更新に使用します。Googleのパスワードはアプリに入力しません。

Google APIから受け取った情報の利用は、Google API Services User Data PolicyのLimited Use要件に従い、ここに記載した機能に限ります。広告配信やデータ販売には使用しません。

外部への通信

認証・トークン更新はGoogleに接続します。チャンネル情報と動画状態はYouTube Data APIから取得します。利用者が承認したアップロードでは、動画ファイル、タイトル、説明、タグ、公開設定などをYouTubeへ送信し、予約操作では対象動画IDと公開予定日時などの設定をYouTubeへ送信します。

台本、音声、画像、字幕はPC上の制作ファイルとして扱います。出典取得機能を使う場合は、指定した参照先へHTTPリクエストを送信します。既定でローカル実行する制作サービスにYouTubeの認証情報は渡しません。

この紹介サイトにはログイン、フォーム、埋め込み動画、分析用スクリプトはありません。GitHub Pagesで閲覧する際のホスティング事業者による処理にはGitHubのプライバシー声明が適用されます。

ローカル保存と認証情報の管理

既定では、OAuthのトークンと利用者が用意するクライアント設定を %LOCALAPPDATA%/YouTubeAutoStudio/credentials/ に保存します。OAuth認証はGoogleの画面で行い、アプリはローカルのループバックアドレスで認証結果を受け取ります。認証ファイルはPCの利用者が管理し、共有フォルダーや公開リポジトリに置かないでください。

チャンネル情報、動画ID、投稿・予約情報、承認記録、取得したAPI応答は、機能によって upload_state/ 内のSQLiteデータベースやJSON、output/ 内の関連記録などに保存されます。制作ファイルもPCに保存されます。

管理対象の投稿状態とチャンネル取得情報には取得日時を記録します。同意済みのダッシュボードを起動している間は起動時と日次で点検します。投稿状態は取得から29日経過した時点で再取得の対象になり、30日経過して再取得できない取得情報は削除します。チャンネル取得情報は30日経過時に更新または削除します。取得日時がない旧記録は点検時に更新または削除します。ダッシュボードの停止中は、期限内にCLIで点検してください。制作成果物、個別の承認記録、再送防止用のローカル識別情報はこの期限処理と分けています。

アクセス権の取り消しとデータの削除

  1. ダッシュボードの「YouTube APIの利用とデータ管理」で、削除またはアクセス権取り消しの対象を表示します。対象を確認して実行すると、管理対象の取得情報を削除します。アクセス権取り消しを選んだ場合はGoogleに取り消しを要求し、成功後にローカルのトークンも削除します。
  2. Googleアカウントのアクセス管理でも、アプリに対応する接続を選んでアクセス権を削除できます。アプリの定期確認で失効が分かった場合は管理対象の取得情報を削除します。ローカルの削除操作も利用できます。
  3. 手動で書き出した報告書や関連JSON、バックアップ、旧タスクログは自動管理の対象外です。保存先を個別に確認し、対象の取得情報を削除してください。

ローカルデータを削除してもYouTube側の動画や予約は削除されません。YouTube側での管理には YouTube Studio を使用してください。
