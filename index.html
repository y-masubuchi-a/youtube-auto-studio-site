個人チャンネル向けのローカルアプリ

YouTube
Auto Studio

台本から動画を制作し、確認した動画をYouTubeへ非公開でアップロード。公開日時の設定と投稿履歴の管理まで、手元のPCで行えます。

制作から予約公開まで

動画制作

台本、画像、ナレーションから字幕付き動画を生成し、完成ファイルをPCに保存します。

アップロード

チャンネル、完成動画、投稿情報を確認して送信します。既定は非公開です。通常の制作ジョブでは、個別承認した限定公開・公開も選べます。

予約公開と投稿管理

非公開動画の公開日時を個別に承認して設定し、YouTubeから結果を取得してローカルの履歴に記録します。

Googleアカウントとの接続

本アプリは YouTube API Services の YouTube Data API v3 を使用します。統合認証は youtube.force-ssl を使用し、チャンネルの確認、承認された動画のアップロードと予約公開、投稿状態の取得を行います。この紹介サイトにログイン機能はありません。

YouTube Auto Studioは独立して開発されたアプリで、GoogleおよびYouTubeの公式サービスではありません。
